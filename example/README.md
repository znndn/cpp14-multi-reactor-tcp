# TCP 回声示例

`testserver.cc` 展示 `TcpServer` 的基本用法：注册连接状态回调与消息回调，消费接收缓冲区，再通过 `TcpConnection::send` 原样发送。

## 启动

在仓库根目录执行：

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build -j2
./build/testserver
```

服务器监听 `127.0.0.1:8080`，使用 10 个额外 I/O 线程。另开一个终端，在同一台机器运行：

```bash
nc 127.0.0.1 8080
```

输入 `hello` 并回车，服务器将返回相同内容。客户端退出后，服务器打印连接断开日志，并继续接受新连接。

## 回调与数据流

1. 主线程接收连接，轮询分配 I/O 线程。
2. I/O 线程读取 socket，将数据放入连接的输入缓冲区。
3. `onMessage` 取出并消费当前可读字节，调用 `send` 回送。
4. 非阻塞写未完成的部分进入输出缓冲区，等待后续可写事件。

示例按字节流回显，一次读取或回调不保证对应一行或一条完整消息。

## 结束示例

在客户端终端按 `Ctrl+C` 可以观察连接断开。在服务器终端按 `Ctrl+C` 则按默认信号行为终止进程，不能用这一操作验证 `TcpServer::stop` 的正常停机流程。

正常停机时，应在主线程调用 `stop`，等待现有连接结束、Channel 注销及线程池回收，在完成回调中退出主事件循环。若客户端始终保持连接，`stop` 会继续等待。
